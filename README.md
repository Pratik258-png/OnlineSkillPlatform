# OnlineSkillPlatform

An AI-powered Online Learning Platform with Certification.

## Features
- Student Registration and Login
- Online Courses and Learning Materials
- AI-Generated Notes
- Quizzes and Results
- AI Viva
- Certificate Generation

## Technologies Used
- HTML, CSS, JavaScript
- PHP
- MySQL
- Bootstrap

## Run Locally
1. Install XAMPP.
2. Copy the project into `htdocs`.
3. Start Apache and MySQL.
4. Import the project database using phpMyAdmin.
5. Open `http://localhost/OnlineSkillPlatform/` in your browser.
